# 批次、来源与评价协议

按[主README](../README_CN.md)顺序运行，每个批次使用独立输入、道路图、划分及输出目录。

四项道路应用为常走路线有序重合、代表路线真实行程覆盖、指定道路来源去向分布、主要路口出口比例。题集和区域在评价各方法前固定；答案来自该方法保存的道路发布，不从其它方法或旧任务分数填补。

全集道路发布用于这些应用。训练专用发布独立保留给隐私攻击及训练来源核查；文件名、进程存在或临时行数均不能证明一次发布或评分已完成。

每次执行保留文档原命令、实际外层命令、内部参数、工作目录、解释器、退出码、耗时和最终输出清单。复用结果时重新核验来源和解析后的数值，不因文本换行差异判定分数变化。

正式大图由第09节收集已完成评分与第05节应用汇总。缺失、不适用、未定义、实测零和明确排除分别展示；不把缺失填成零，也不从历史图补数。
