# 全集与训练专用发布

正式命令统一见[主README](../README_CN.md)。本页只解释两类输入，不提供第二套运行命令。

全集发布使用冻结全集，供统计、道路评分及第05节四项道路应用使用。北京示例为15730槽，包含未产出或拒绝的槽位。

训练专用发布只读取冻结训练划分，并记录生成来源；北京示例为12584槽，另有3146槽测试集。训练专用发布仍供隐私攻击及训练来源检查使用，不得把全集发布冒充训练发布。

第05节的四项道路应用从已保存的完整道路轨迹直接计算答案，不训练旧的下一格、目的地、道路续接或检索预测器。真实数据固定题目和参考答案，各合成方法回答同题，再按同一指标比较。

切换城市时先按第01节统一预处理和固定划分；不能仅修改文件名、槽位数或城市标签来复用旧城市输入。
