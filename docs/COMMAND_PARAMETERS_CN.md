# 常用参数说明

可直接执行的完整命令见[主README](../README_CN.md)。默认以北京为例，城市预处理配置在第01节选择；本页不另列一套命令。

| 参数 | 含义 |
| --- | --- |
| `--config` | 当前步骤的配置文件；应用配置由第05节的configure命令生成 |
| `--input` | 对应上游已完成产物，不是待生成文件 |
| `--out` / `--out-dir` | 本次新的输出目录，不覆盖旧结果 |
| `--method` | 合成方法名称；应用answer使用配置中登记的名称 |
| `--router` | 道路处理方法；原生方法只使用自己的道路发布 |
| `--train-only` | 只用冻结训练划分生成，供训练来源检查和攻击实验 |
| `--slots` | 包括空槽在内的完整发布数量，不是有效轨迹数量 |
| `--public-edges` | 本城市公共图的统一有向边与几何 |
| `--questions` / `--region` | 在各方法评价前固定的本城市题目和区域 |
| `--release 名称=文件` | 登记一个方法的完整道路槽位文件，可重复指定 |
| `--reference` | 同配置、同题集的真实参考答案目录 |
| `--applications` | 第05节已完成的答案汇总，供第09节收集 |
| `--spec` | 当前11指标矩阵规格spec_framework.json |

应用输入的转换只改变道路表示，不补路、不重新匹配。坐标Origin没有道路对象时记为不适用；公共控制及原生方法需要各自真实产物。
