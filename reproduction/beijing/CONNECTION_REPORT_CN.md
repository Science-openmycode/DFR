# 三处新批次接续已接通

日期：2026-10-24。范围为北京Windows交付目录。只修改执行记录、路径、结果汇总、命令与绘图入口，不修改算法核心、原合成数据、旧分数、论文或GitHub。

## 1. 新原生发布到严格TSTR

完整命令在 `REPRODUCE_NATIVE_TSTR_CN.md`，README及索引均已链接。

- DPMM：生成前登记文档原句；直接运行原生成命令；紧接着记录PowerShell真实退出码。验证器核对训练输入、加速验证、生成产物后恢复原槽位，写出新的lineage。失败保留finish记录但不写verified记录，不复制旧执行回执。
- MTNet：原GPU启动脚本保存它实际观察到的训练及生成子进程退出码；核验器读取 `trained/model.pt`、30轮日志、训练划分及原生输出。记录明确是子进程证据，不冒充外层启动证明。
- DFR：已有训练专用生成记录继续使用；原生节点对仅作道路表示转换，再转确定几何。三个方法均接入同一个严格TSTR评分入口，不再匹配原生轨迹。

DPMM的手动start/finish记录反映操作者按原文执行并提交退出码，不是操作系统级自动证明。文档要求三条连续执行；不能把其它命令的退出码填进去。

## 2. K诊断汇总

`tools/collect_portable_sweeps.py` 现在除四类评分汇总外，还输出 `endpoint_diagnostics.json`：

- 原端点选中真实质量比例；
- 原端点噪声L1；
- endpoint fallback及single-edge fallback；
- 六档K、每档五种子、六项指标相对K384的同种子配对差。

公式来自原K收集器，路径改用本目录。输出标明私有研究诊断，不把真实统计当DP发布字段。summary、CSV、diagnostics和诊断代码均记录摘要。

## 3. 新评分目录到矩阵

`REPRODUCE_NEW_MATRIX_CN.md` 提供两个独立命令：先收集多个新评分根目录，再使用原绘图函数作图。重复格子冲突时停止；未评分格子保留MISSING；原生方法不展开为多个R。

新绘图入口加 `--new-batch`，记录相对旧图的逐值变化，允许真正重算的分数发生变化。旧冻结重画模式仍要求既有数值不变。两种模式均使用原版式、分组和配色，不用旧分数填新矩阵。

## 使用与边界

复制本目录后按README安装锁定环境，按各章节顺序运行。新原生生成必须成功退出后再登记，不能跳过失败；已保存结果可以直接复评/作图。MTNet仍要求CUDA硬件和依赖，软件安装需要可用的软件源。

本轮没有在另一台空白机器重新训练所有正式实验，也没有把参数测试称为正式复现实验。接通指上述三个断口已有相应代码、具体独立命令和针对性运行验证；不宣称未来任意环境绝无故障。当前绘图使用既有已验证绘图函数，新批次图需先有新批次成绩；本轮未用测试夹具发布科研图。
