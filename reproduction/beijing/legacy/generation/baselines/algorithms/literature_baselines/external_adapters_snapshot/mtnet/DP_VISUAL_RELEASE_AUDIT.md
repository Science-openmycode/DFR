# DP-SGD 可视化发布审计

## 结论

早期 `origin_conditioned` 图不是无条件 DP 合成发布：它将真实轨迹的首道路边和首时间槽作为模型生成条件。即使模型参数由 DP-SGD 训练，直接把私有条件传入输出也不是训练后处理，不能作为 DP synthetic release 的可视化证据。

这也解释了旧图为何显得异常接近真实数据。道路拓扑掩码保证所有解码结果沿公开 OSM 连通；真实起点/时间又把每条轨迹锚定到私有分布。该图只可作条件模型诊断，不能用于论文的 DP 质量结论。

## 修正后的发布协议

`generate_plot_paper_dpsgd_transfer.py --condition-source public --release-size N` 使用固定的公开 `N`、固定随机种子、公开 OSM 边集合均匀采样的起始边，以及公开零时间槽。真实 FMM 轨迹仅用于左侧评估面板，不进入生成器。因而生成结果是经 DP 训练模型的后处理。

历史 L=200 检查点使用 30 次固定批更新、`C=1` 和 `sigma=26.841451659207394`。它曾按加入/删除邻接的 Gaussian-RDP 组合标为 `(epsilon,delta)=(1,10^-5)`；但固定 `B=N` 实现没有 canonical null slot，实际执行保持记录数不变，应按替换一条完整轨迹会计。替换邻接下裁剪和的敏感度为 `2C`，相同检查点的上界约为 `(2.042,10^-5)`。因此该历史检查点只能作为诊断产物，不能再称为严格 `epsilon=1` 发布。完整推导、重算器和重训练要求见 `docs/MTNET_FIXED_BATCH_DP_ACCOUNTING_AUDIT_20260717.md`。

## 解释

修正后的 public-seed 图仍会严格沿道路，这是公开道路邻接掩码的性质，不是私有效用；但其空间需求分布明显更宽、更接近公开种子分布。这是预期且诚实的结果：在本数据规模、模型维度和严格总预算下，强 DP 噪声与几乎 100% 的梯度裁剪显著压低了私有出行偏好的学习信号。
