# 统一城市数据接口（开发中）

同一算法入口读取两类配置：原有配置完全沿用旧路径规则；新配置使用 `dataset_bundle` 指向标准数据包说明。当前接入 DFR 全集/训练、四种统计 M 的独立生成、路由、道路评分及坐标评分入口；原生基线、时间准备及其它评价尚待迁移，不能当作全流程交付。

数据包说明 `dataset.json` 示例（路径相对于本文件）：

```json
{
  "schema": "road-experiment-bundle-v1",
  "dataset": "porto",
  "paths": {
    "prepared": "prepared",
    "network": "public/network.shp",
    "metric_cache": "public/metric_cache.pkl.gz"
  }
}
```

实验配置用 `"dataset_bundle": "../data/porto/dataset.json"` 引用它，保留 epsilon、seed、batch、算法配置及 legacy/output 路径。入口从 prepared/canonical_manifest.json 自动读取城市、总/训练/测试数量和数据标识，不要求用户填写哈希字符串。已有算法内部的来源检查尚未改变；数据包文件存在不代表已完成预处理或可运行。

数据包路径相对于 dataset.json，dataset_bundle 相对于实验配置。旧配置的路径仍相对于历史入口目录。不允许实验配置同时指向冲突的城市、人口或训练文件；这样的冲突直接报错，不静默选择其中一个。相同的模式适用于北京、Porto及其它已正确预处理的城市，不在读取器中按城市名称分支。

首轮12项测试通过；第二轮26项配置、数据合同、坐标资源及保存结果解析测试通过，包含统计生成/路由/道路评分三个入口的新配置与等价旧配置内部命令逐项相等。该比较只为dry-run，没有运行实验。尚未运行北京真实资源回归、Porto真实端到端或正式生成。这里不改变DFR算法，也没有解决DFR公共分区约束和作者图字段转换；这些仍属于后续公共资源/数据适配工作，不能仅靠新配置绕过。

数据包可提供 `bbox` 和 `routing_crs`，共同入口直接读取；若实验配置同时给出不同值则报错，避免悄悄使用另一个城市的范围或投影。道路评分的真实道路和道路图路径默认对应 prepared/road_records.pkl.gz 和公共network；需要不同指标表示时必须显式提供对应路径，不自动重新匹配或转换道路。

## 原生入口接入进度（2026-10-29）

MTNet准备入口现在也读取dataset_bundle。新数据包可在paths中提供 `time_endpoints`，为含source_index/start_ts/end_ts的CSV；按冻结source_indices精确选择对应记录，检查缺失、重复、非有限及逆序端点。数据包也可提供历史 `mtnet_time_binding` 和 `mtnet_raw_reference`；旧命令显式参数仍然可用。不能同时提供两种时间输入。两种输入均沿用原作者按道路长度分配轨迹总时长的规则，不把插值当作原始逐道路时间。原始作者格式的内部目录名beijing_roads_l20暂保留作兼容名称，不代表把Porto数据当北京。

真实输入验证：北京15730条准备退出0，原loader可训练852条；Porto既有5000条隔离真实样本先发现highway字段缺失，修复后准备退出0、可训练10条。缺失等级沿用原构建器既有回退桶6并记录，不猜测作者数字等级；不声称这些是service道路。两个准备结果的数据文件SHA独立复核通过。Porto可训练数量少是本次原筛选下的实际结果，不修改筛选阈值来凑数。命令和失败证据见外部执行账本。

DPMM入口已读取同一配置，公共投影由配置解析而非固定北京50/S；原验证文件与新输入一致性检查仍保留。Porto原版/加速等价验证及真实生成尚未通过。MTNet部署、训练、原生发布、严格TSTR、其它评价和完整README尚未完成。不能把本开发说明当作完整可运行交付。
