# Beijing full drivable public network

`beijing_full_20261026.zip` contains the frozen public network (`network/`)
and its underlying OSM cache (`osm/`). It contains no GPS trajectories,
matched private paths, measurement transcripts or synthetic experiment results.
This is the larger network used by the 15,730-road-trajectory workflow;
it is not the legacy `beijing_network/` snapshot.
